# HireFlow

HireFlow is a full-stack job recruitment platform built with Django, MySQL and Django REST Framework.

It provides separate workflows for job applicants and recruiters, allowing users to discover jobs, apply for positions, manage applications and manage job postings.

## Features

### Applicant

- User registration and login
- Applicant profile
- Skills and bio management
- Browse available jobs
- Search jobs by title, company and skills
- Filter jobs by location and job type
- Apply for jobs
- Upload resume
- Add cover letter
- Track application status
- View submitted applications

### Recruiter

- Recruiter registration and login
- Recruiter dashboard
- Create job postings
- Edit job postings
- Delete job postings
- View applications
- Review applicant information
- Track application statuses

### REST API

- Job API
- Application API
- Django REST Framework integration
- JSON-based API responses
- Browsable API interface
